# APSHABD Typeface Direction

## Posts

- Major/display type: use the chunky, rounded modular lettering shown in `trench-slab/reference/major-post-typeface-reference.png`.
- Supporting and body text: Trench Slab Regular.
- Primary type color: warm heritage cream `#C4AC90`, sampled from the approved APSHABD post reference.
- On major posts, use the cream whenever it has strong contrast with the background. For light or similarly toned backgrounds, switch to the dark ink counterpart rather than forcing the cream.

## Website

- Trench Slab Regular is the primary Latin body typeface across the website.
- The primary website typography color is warm heritage cream `#C4AC90`.
- Existing script-specific fonts remain in place for Indian-language text so those characters render correctly.
- Existing display treatments remain available for campaign-scale headlines and special effects.

## Included font files

- `trench-slab/TrenchSlab-Regular.otf` — desktop/design applications.
- `trench-slab/TrenchSlab-Regular.woff2` and `.woff` — web use.
- `trench-slab/FFL.txt` — font license supplied with the source package.
