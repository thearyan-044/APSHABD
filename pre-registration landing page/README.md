# APSHABD Pre-registration

Standalone early-access landing page for APSHABD drops.

## Live site

https://thearyan-044.github.io/APSHABD-pre-registration/

## Included

- Responsive pre-registration form
- Required Instagram follow confirmation
- Google Sheets registration storage
- Automated email confirmation with a unique verification link
- Branded success and email-confirmation states

The browser form submits to the deployed Google Apps Script endpoint configured in `config.js`. The server-side Apps Script source and deployment guide are included for maintenance.
